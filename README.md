# รู้ทันน้ำตาลและไขมัน (เวอร์ชันใช้งานส่วนบุคคล)

แอปแปลผลเลือดเบื้องต้นและบันทึกน้ำตาลปลายนิ้ว ข้อมูลของผู้ใช้เก็บอยู่ในเครื่องของผู้ใช้เท่านั้น ไม่มีเซิร์ฟเวอร์และไม่มีการส่งข้อมูลกลับมาที่ผู้พัฒนา

## ไฟล์ในโฟลเดอร์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวแอปทั้งหมด (หน้าจอ เกณฑ์แปลผล และการบันทึก) |
| `manifest.webmanifest` | ทำให้ติดตั้งเป็นแอปบนหน้าจอหลักได้ |
| `sw.js` | เก็บไฟล์ของแอปไว้ให้เปิดได้ตอนไม่มีอินเทอร์เน็ต (ไม่เก็บข้อมูลผู้ใช้) |
| `icon-192.png`, `icon-512.png` | ไอคอนแอป |

## นำขึ้นเว็บ (ฟรี) ด้วย GitHub Pages

1. สมัครหรือเข้าสู่ระบบ github.com แล้วสร้าง repository ใหม่ แบบ Public
2. อัปโหลดไฟล์ทั้ง 5 ไฟล์ในโฟลเดอร์นี้ (ไม่ต้องอัปโหลด README ก็ได้)
3. ไปที่ Settings > Pages เลือก Branch: `main` โฟลเดอร์ `/ (root)` แล้วกด Save
4. รอ 1–2 นาที จะได้ลิงก์ `https://ชื่อผู้ใช้.github.io/ชื่อ-repository/`
5. ส่งลิงก์หรือทำเป็น QR code ให้ผู้ใช้ เปิดแล้วติดตั้งลงหน้าจอหลักตามคำแนะนำในแอป

ต้องเปิดผ่านลิงก์ `https://` เท่านั้น การเข้ารหัสไฟล์สำรอง การติดตั้งเป็นแอป และการใช้งานออฟไลน์จึงจะทำงาน

เมื่อแก้ `index.html` แล้วอัปโหลดทับ ให้เปลี่ยนเลข `CACHE` ใน `sw.js` (เช่น `dmcare-app-v3`) เพื่อให้เครื่องผู้ใช้โหลดเวอร์ชันใหม่ ข้อมูลที่ผู้ใช้บันทึกไว้จะไม่หาย

## แก้เกณฑ์แปลผล

เกณฑ์ทั้งหมดอยู่ในตัวแปร `CFG` ส่วนต้นของ `<script id="logic">` ใน `index.html` ควรให้แพทย์ทบทวนกับแนวทางเวชปฏิบัติสำหรับโรคเบาหวานฉบับล่าสุดก่อนเผยแพร่

## การออกแบบด้านข้อมูลส่วนบุคคล (PDPA)

- เก็บข้อมูลในเครื่องของผู้ใช้เท่านั้น ผู้พัฒนาไม่ได้รับและเข้าถึงข้อมูลไม่ได้
- ไม่มีระบบติดตามการใช้งาน โฆษณา หรือคุกกี้ของบุคคลอื่น
- ขอความยินยอมแยกตามโปรไฟล์ก่อนเก็บข้อมูลสุขภาพ
- ไม่เก็บชื่อจริง เลขบัตรประชาชน เบอร์โทร หรือที่อยู่
- ผู้ใช้ขอสำเนา ลบ และถอนความยินยอมได้เองในแอป
- ไฟล์สำรองตั้งรหัสผ่านได้ (เข้ารหัส AES-256-GCM)
- PIN แยกตามโปรไฟล์ สำหรับเครื่องที่ใช้ร่วมกันในครอบครัว

## ขอบเขตที่ไม่ต้องขอจริยธรรมการวิจัยใหม่ (ควรยืนยันกับคณะกรรมการจริยธรรม)

แอปนี้เป็นการนำผลงานวิจัยไปใช้ประโยชน์ ผู้พัฒนาไม่ได้เก็บหรือวิเคราะห์ข้อมูลของผู้ใช้ หากต่อไปต้องการทำสิ่งต่อไปนี้ ต้องยื่นขอจริยธรรมการวิจัยก่อน

- เก็บข้อมูลหรือไฟล์ของผู้ใช้มาวิเคราะห์ หรือรายงานผลการใช้แอป
- ทำแบบสอบถามความพึงพอใจหรือประเมินผลกับผู้ป่วย
- เพิ่มระบบส่งข้อมูลเข้าฐานข้อมูลกลาง หรือให้ผู้วิจัยดูข้อมูลของผู้ใช้
